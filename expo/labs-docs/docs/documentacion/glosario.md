# Glosario de términos

| Término | Qué significa |
|---|---|
| **API** | Una puerta para que dos programas se hablen. Por ejemplo, la app le pide respuestas a Claude por su API. |
| **API key (llave de API)** | Contraseña que identifica a tu cuenta ante un servicio, como Anthropic. Es secreta. |
| **Claude** | El modelo de inteligencia artificial de Anthropic que genera las respuestas del asistente. |
| **Categoría** | El tipo de registro de campo: maquinaria, rendimiento, insumos o resumen. Cada una va a su propia pestaña. |
| **Contenedor** | Un programa empaquetado con todo lo que necesita para correr. Docker los crea y los arranca. |
| **Cuenta de servicio** | Un "usuario robot" de Google con el que la app escribe en Google Sheets sin usar la cuenta de una persona. |
| **Docker Compose** | La herramienta que levanta varios contenedores juntos a partir del archivo `docker-compose.yml`. |
| **`.env`** | Archivo con la configuración privada, como las llaves. Nunca se sube al repositorio. |
| **HTTPS** | Conexión cifrada. Es obligatoria para usar el micrófono en el navegador. |
| **Ollama** | Programa para correr modelos de IA en tu propio servidor, sin depender de un proveedor externo. |
| **OpenWebUI** | Interfaz de chat completa, con usuarios e historial, conectada al asistente. |
| **Palabras clave** | Las palabras que hacen que un mensaje se registre como reporte, como "litros", "poda" o "tractor". |
| **Proxy inverso** | Un servidor que recibe las visitas en tu dominio con HTTPS y las pasa a la app. Por ejemplo, Nginx o Caddy. |
| **Reporte de campo** | El archivo de Excel del día donde se acumulan los registros de la operación. |
| **Socket.IO** | La conexión en tiempo real que usa el chat web para mostrar la respuesta mientras se escribe. |
| **Streaming** | Recibir una respuesta en fragmentos, conforme se genera, en vez de esperar a que esté completa. |
| **Webhook** | Una dirección que un sistema llama para avisar a otro que pasó algo. Ver [Webhooks](../tools/webhooks.md). |

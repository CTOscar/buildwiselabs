## Prioridades

Para atender primero lo urgente, cada reporte se clasifica así:

| Prioridad | Cuándo |
|---|---|
| **Alta** | El chatbot no responde o no está guardando reportes. |
| **Media** | Algo funciona mal, pero hay forma de seguir trabajando. |
| **Baja** | Dudas, mejoras y solicitudes nuevas. |

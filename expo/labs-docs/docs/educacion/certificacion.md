# Certificación básica

Una persona del equipo está lista para operar el chatbot cuando puede hacer, sin ayuda, todo lo de esta lista.

## Operador

- [ ] Abrir el chat en la computadora y en el celular.
- [ ] Registrar un reporte de maquinaria por texto y comprobar la confirmación.
- [ ] Registrar un reporte de rendimiento **por voz**.
- [ ] Reportar una incidencia (falta de personal, falla, lluvia).
- [ ] Subir un archivo de combustible y descargar el resultado.
- [ ] Encontrar el reporte del día en el visor de reportes.

## Administrador

Todo lo del operador, más:

- [ ] Levantar, reiniciar y actualizar el chatbot. Ver [Cómo levantar un bot](../iniciar/levantar-bot.md).
- [ ] Revisar los registros y reconocer `Claude test: OK ✓`.
- [ ] Agregar una palabra clave de registro y probarla.
- [ ] Respaldar los reportes y los volúmenes.
- [ ] Crear y desactivar usuarios en OpenWebUI.
- [ ] Resolver los problemas de [Solución de problemas](../chatbot/operacion/solucion-de-problemas.md).

:::info Por completar
Si quieres entregar una constancia formal, aquí va el proceso: quién evalúa, cómo y qué documento se entrega.
:::

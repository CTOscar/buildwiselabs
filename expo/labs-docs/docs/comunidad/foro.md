# Foro de usuarios

El foro es el lugar para preguntar cómo otros resolvieron algo, compartir flujos y proponer mejoras.

:::info Por completar
El foro todavía no está abierto. Mientras tanto, la comunidad se reúne en el [Canal de Discord](./discord.md), y las dudas puntuales se atienden en [Contacto directo](../soporte/contacto.md).
:::

## Cómo escribir una buena pregunta

- Un título que diga el problema: "No se registra el diésel desde el celular" en vez de "Ayuda".
- Qué intentaste y qué pasó.
- Sin llaves, contraseñas ni datos de clientes.

# Canal de Discord

En Discord está el equipo de BuildWise Labs y los usuarios de los servicios: avisos de nuevas versiones, dudas rápidas y casos compartidos.

:::info Por completar
Aquí va el enlace de invitación al servidor cuando esté listo.
:::

## Canales

| Canal | Para qué |
|---|---|
| `#anuncios` | Versiones nuevas, mantenimientos y cambios importantes. |
| `#ayuda` | Dudas de uso y configuración. |
| `#casos-de-uso` | Comparte cómo usas el chatbot en tu operación. |
| `#ideas` | Propuestas de mejoras. |

## Avisos automáticos

El mismo servidor puede recibir avisos del sistema, como errores o despliegues, con un webhook. Ver [Webhooks → Discord](../tools/webhooks.md#discord).

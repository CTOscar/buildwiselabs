# Hoja de ruta

:::info Por completar
Las prioridades y fechas las define el equipo. Mientras tanto, esta es la lista de pendientes técnicos que salen de revisar el código actual.
:::

## Pendientes técnicos

| Pendiente | Por qué |
|---|---|
| Contraseña en las rutas de reportes | Hoy cualquiera con la dirección puede descargar los Excel. Ver [Seguridad](./seguridad.md#los-reportes). |
| Corregir `/v1/chat/completions` sin streaming | Responde con error. Ver [Limitaciones](./limitaciones.md#técnicas). |
| *Streaming* real en `/v1` | Que las respuestas en OpenWebUI empiecen a aparecer de inmediato. |
| Historial en el chat web | Que la conversación no se pierda al recargar la página. |
| Extracción con IA también en el Excel del día | Que el Excel y Google Sheets tengan los mismos campos completos. |
| Modelo configurable por variable de entorno | Cambiar de modelo sin tocar el código. |

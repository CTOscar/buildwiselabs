Glosario de términos

TérminoQué significa
APIUna puerta para que dos programas se hablen. Por ejemplo, la app le pide respuestas a Claude por su API.
API key (llave de API)Contraseña que identifica a tu cuenta ante un servicio, como Anthropic. Es secreta.
ClaudeEl modelo de inteligencia artificial de Anthropic que genera las respuestas del asistente.
CategoríaEl tipo de registro de campo: maquinaria, rendimiento, insumos o resumen. Cada una va a su propia pestaña.
ContenedorUn programa empaquetado con todo lo que necesita para correr. Docker los crea y los arranca.
Cuenta de servicioUn "usuario robot" de Google con el que la app escribe en Google Sheets sin usar la cuenta de una persona.
Docker ComposeLa herramienta que levanta varios contenedores juntos a partir del archivo docker-compose.yml.
.envArchivo con la configuración privada, como las llaves. Nunca se sube al repositorio.
HTTPSConexión cifrada. Es obligatoria para usar el micrófono en el navegador.
OllamaPrograma para correr modelos de IA en tu propio servidor, sin depender de un proveedor externo.
OpenWebUIInterfaz de chat completa, con usuarios e historial, conectada al asistente.
Palabras claveLas palabras que hacen que un mensaje se registre como reporte, como "litros", "poda" o "tractor".
Proxy inversoUn servidor que recibe las visitas en tu dominio con HTTPS y las pasa a la app. Por ejemplo, Nginx o Caddy.
Reporte de campoEl archivo de Excel del día donde se acumulan los registros de la operación.
Socket.IOLa conexión en tiempo real que usa el chat web para mostrar la respuesta mientras se escribe.
StreamingRecibir una respuesta en fragmentos, conforme se genera, en vez de esperar a que esté completa.
WebhookUna dirección que un sistema llama para avisar a otro que pasó algo. Ver Webhooks.
